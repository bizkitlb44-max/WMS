# WMS 대시보드 데모

HTML·CSS·JavaScript만으로 만든 가장 간단한 형태의 창고관리시스템(WMS) 대시보드입니다.
데이터는 `data/wms-data.json`의 더미 데이터를 사용합니다.

**접속 주소:** https://bizkitlb44-max.github.io/WMS/

## 구성 화면
| 영역 | 내용 |
|---|---|
| KPI 카드 | 보유 SKU, 재고 금액, 금일 입·출고, 재고 정확도, 정시 출고율, 로케이션 사용률, 안전재고 미달 |
| 입출고 추이 | 최근 14일 입고/출고 건수 막대 차트 (SVG) |
| 존별 로케이션 사용률 | A~D 존 사용 셀 / 전체 셀 |
| 금일 출고 주문 | 대기 → 피킹 → 포장 → 출고완료 진행 현황 |
| 안전재고 미달 알림 | 안전재고 대비 부족 수량 |
| 재고 현황 | 검색, 존 필터, 미달만 보기, 열 정렬 |
| 입출고 이력 | 입고/출고/이동/재고조정 탭 필터 |

## 파일 구조
```
index.html          화면
css/style.css       스타일
js/app.js           JSON 로드 및 렌더링
data/wms-data.json  더미 데이터
```

## 로컬 실행
`fetch()`로 JSON을 읽기 때문에 파일을 직접 열지 말고 웹 서버로 실행합니다.
```
python -m http.server 8000
```
브라우저에서 http://localhost:8000 접속.
